# CHGIS 数据获取与 150–300 年提取

访问日期：2026-09-25。处理脚本：`data/scripts/extract_chgis_150_300.py`。筛选规则：`BEG_YR <= 300` 且 `END_YR >= 150`（起止年按数据字典均为有效年，含端点）。四个断面年再取 `BEG_YR <= 年 <= END_YR`。输出为 WGS84 GeoJSON。

## 结论

拿到了可用的府级点、部分府级面、县级点和少量州级面/点。150–300 年间府级点有 364 条时间实例、244 个简体地名；同年在册记录数从公元 190 年的 92 条增至 270 年的 157 条。府级多边形只覆盖东南，公元 190 年 17 个面，对不上华北、关中、巴蜀和河西的郡。

没有魏、蜀、吴、晋的政权界线。公开的“政权”时间序列只有 11 个面、6 个点，全是公元 909–1683 年的闽国、殷国、清源、平海、东都、东宁，与 150–300 年无交集，因此没有写出 `chgis_polity_150_300.geojson`。

| `chgis_pref_pgn_150_300.geojson` | 3830 | 116 | 53 | EPSG:4326 |

| 政权面/点 | 11 / 6 | 0 | — | 西安 1980 19 带；未写出 GeoJSON |

V6 的 `*_utf_wgs84` 带 `.cpg`，内容为 `UTF-8`，pyogrio 直接读出简体与繁体。抽查：府级点首条相交记录为「新兴郡 / 新興郡」，215–295 年。

V4 省级 shapefile 没有 `.cpg`。字节是 UTF-8，GDAL 按单字节码页读成乱码。脚本把尚不含汉字的文本按 Latin-1 还原为 UTF-8。还原后州名是「扬州」「荆州」「交趾」等。

Shapefile 字段与数据字典（`gisinfo_table`）的对应关系：

| 字段 | 含义 |
| --- | --- |
| `NAME_PY` | 罗马字 |
| `NAME_CH` | 简体 |
| `NAME_FT` | 繁体 |
| `BEG_YR` / `END_YR` | 该实例开始生效的年 / 失效前最后一年 |
| `BEG_RULE` / `END_RULE` | 定年方式。4 = 具体年份，5 = 具体月，6 = 具体日，1–3 = 按朝代或年号笼统定年 |
| `TYPE_PY` / `TYPE_CH` | 政区类型。郡、国、侯国、尹、州、典农校尉等都可能出现在府级层 |
| `LEV_RANK` | 相对等级，便于排序，不是法定层级代码 |
| `SYS_ID` | 空间对象唯一 ID |
| `NOTE_ID` | 连到考释的编号 |
| `PRES_LOC`（府级面里写作 `PERS_LOC`） | 今地描述，不是上级政区 |
| `X_COOR` / `Y_COOR` | 十进制度经纬度（省级原文件在投影坐标里另有 `X_COORD`） |

上级统属在关系数据库的 `partof_table`（子级 ID、父级名称、关系起止年）里，不在这些 shapefile 属性中。V4 总包里有 `access_database/v4_chgis_dbase.mdb`，本次没有整库导入。下面四个年份的“所属州”是治所点落入同年州级多边形的空间套合，不是 CHGIS 的统属表。套不中的记为无。

## 150–300 年的府级单位

“在册”按时间实例计，不是去重地名。同一年同一地名可以有两条都有效的记录（例如公元 190 年东海郡、合浦郡、苍梧郡、长乐郡各两条）。府级层里还混有州、尹、侯国、典农校尉、都督，不完全是郡/国。

| 年 | 点记录 | 其中类型 | 有多边形的地名 | 点有而面无 |
| --- | --- | --- | --- | --- |
| 190 | 92 | 郡 70、国 16、侯国 2、尹 2、州 2 | 17 | 其余郡国 |
| 210 | 111 | 郡 95、国 10、尹 2、州 2、侯国 1、典农校尉 1 | 23 | 其余 |
| 240 | 131 | 郡 109、国 11、侯国 3、尹 2、州 4、都督 1、典农校尉 1 | 24 | 其余 |

## 政权界线

魏、蜀、吴、晋都没有政权多边形或政权治所。地名里的“魏郡、魏兴郡、蜀郡、吴郡、晋安郡”是郡名，不是三国或西晋的政权界。

## 缺口

- 东汉和三国的郡，点比面全得多。面只覆盖东南，不能直接做中原、关中、巴蜀、河西的郡界。
- 州界更稀，而且 210 年缺扬州面。北方各州没有面。
- 没有魏、蜀、吴、晋的政权界和政权治所。
- 边疆：点层有河西四郡和金城，未见西域都护府所辖绿洲。190 年有右北平、渔阳、上谷，未见辽东、玄菟、乐浪；辽西要到 270 年的点才出现。南界到交趾、合浦、朱崖一带，再向西南的非汉政权没有面。
- 鲜卑、羌、乌桓、山越等没有独立图层。
- 县级只有治所点，没有全国县级时间序列多边形。V4 另有“福建县级界线”，范围不是全国，本次未提取。
- 府级层混有州、尹、典农校尉、都督；同一年同名多条。做地图前要按 `SYS_ID` 处理重叠，不能把记录数当成郡国总数。
- 上级州要靠统属表。本次空间套合只在有州界的南方有效，不能当成东汉十三州的完整归属。

## 脚本

`data/scripts/extract_chgis_150_300.py`

用 `data/.venv` 里的 Python 3.12 运行（geopandas、pyogrio、shapely、pyproj）。它读取上面的 shapefile，按年份相交筛选，把西安 1980 投影转到 WGS84，修复无 `.cpg` 的 UTF-8 中文，写出 GeoJSON，并把断面统计写到 `data/derived/chgis_150_300_summary.json`。政权层读入后因无交集而不写空文件。
