# 南方八城（三国原型）

地图地名取 `names` 里满足 `from ≤ 年份 < to` 的一条。最后一条的 `to` 为 `null`，表示用到今天。`lng`、`lat` 是打点用的古城址中心（WGS84，十进制 3 位）。和今天城区中心不是同一点时，另给 `ancient_site` 与 `modern_center`。公元前用负数。边界说不准的，写在 `note` 里。

`related_sites`、`earlier_site` 是邻近而不是同一座城的地点，供地图区分，不要和主点叠成一个坐标。
