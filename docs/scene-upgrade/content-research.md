# 三个精修场景：内容核查与叙事依据

核查日期：2026-09-30。受众为12–15岁。本次只新增独立场景数据，不覆盖旧事件、人物和专线。每个场景五段、手动步进；不添加测验、打分或学习记录。

## 内容方法与来源边界

以可访问原典全文核对具体叙事。维基文库是古籍全文的公开转录载体，不是官方校勘版；本次引用其中的《三国志》与《晋书》原典，不引用百科条目作事实依据。页面版本、字形与断句可能不同，正式出版前可再用可靠点校本复核。

把原典记录、教学推理和艺术表现分开。短正文承担故事，`evidence` 说明观察重点，`boundaries` 保存精度和争议边界。人物肖像均须标明“艺术想象”，不能宣传为真实相貌复原。

接口保存在 `prototype/src/data/scenes.ts`：

- `SceneDefinition`：`id / eventId / title / kicker / question / summary / portraitId / people / steps / sources / boundaries`。
- `SceneStep`：`id / title / text / focus / year / yearLabel / center / zoom / lines? / portraitIds? / evidence`。`center` 为 `[number, number]`。`focus` 分为地理、人物、制度、结果四种观察重点。
- `evidence`：`{ label, text }`；`sources`：`{ title, url, note? }`；`people`：`{ id, name, role }`。
- 导出 `scenes`、`sceneById`、`sceneByEventId`。无自动计时、无自动推进、无新路线几何；地图镜头使用背景年份，界面应优先显示 `yearLabel`。

主肖像沿用旧人物 ID `zhouyu`、`dengai`。陈群在原人物库中不存在，`chenqun` 是本场景独立身份。其他人物 ID 仅用于场景关联；前端不能假定每个 ID 都能从旧人物库检索到资料。

## 赤壁之战：江是阻隔，也是通道

依据：[《三国志》卷五十四·周瑜传及裴松之注](https://zh.wikisource.org/wiki/三國志/卷54)。已在线核对曹操接收荆州水军、孙刘合作、曹军疾病、黄盖诈降与火攻、败退后曹仁留守江陵。

五段依次为：长江防线改变 → 联盟与军队状态 → 火攻机制 → 战役结果与三国建立的区别 → 史料与小说边界。主问题是“占住北方之后，为什么仍跨不过这段长江？”主肖像为周瑜，避免用诸葛亮的神奇东风作为视觉高潮。

本传写火攻时风势猛烈；裴注引《江表传》写东南风。两层记录不能混成一本传明确的精确气象报告。诈降、薪草和油料、船舰首尾相接有记录；不由此虚构铁链结构、舰船数量、每条船停泊位置。地图采用今赤壁一带示意定位，古战场争议和古河岸变化保留在场景说明中。

本场景只写208年冬，不沿用旧数据字段与注记之间不一致的十月/十二月选择。火攻改变战局，不等于208年已经完成三国政权分界。河流既作障碍也作运输通道，是地理与作战方式相连的教学解释。

## 九品中正：评价本身，也是一种权力

创制依据：[《三国志》卷二十二·陈群传](https://zh.wikisource.org/wiki/三國志_(四庫全書本)/魏志/卷22)。在线核对建法在曹丕即魏王位后、称帝之前的叙述位置。原传简短，不据此编造完整220年法令。

背景与变化依据：[《晋书》卷三十六·卫瓘传](https://zh.wikisource.org/wiki/晉書/卷036)。已在线核对卫瓘回顾战乱后人士流移、最初仍有乡邑清议、后来按资望定品的叙述。**这是西晋人的回顾，不能当作陈群留下的立法宣言。**

权力批评依据：[《晋书》卷四十五·刘毅传](https://zh.wikisource.org/wiki/晉書_(四庫全書本)/卷045)。在线核对其对中正偏私、缺少约束、申诉受限、等第偏向势族的批评。不把上品/寒门的概括机械解释为每个时期绝无例外。

五段依次为：战乱后的识人难题 → 人物品评进入选官 → 评价者的判断 → 西晋时的资望与门第变化 → 检查评价理由。主问题是“把人才分成九等，就能让选官更公平吗？”主肖像为陈群。

“人物—中正品评—朝廷选用”是简化教学关系，不是一张存世原表。九品人物等第不是九档考试分数，也不能等同于官职品级。第4–5段明确进入西晋初年：地图背景采用280，不宣称卫瓘、刘毅的奏疏恰好写于该年。评价者如何掌握信息、如何避免偏好，是从史料问题引出的教学观察，不倒推220年已全按门第选人。

## 阴平灭蜀：绕过关口，仍要付出代价

路线、机制与战事依据：[《三国志》卷二十八·邓艾传](https://zh.wikisource.org/wiki/三國志_(四庫全書本)/魏志/卷28)。已在线核对姜维退守剑阁、钟会攻而未克、邓艾的绕行计划、修路造桥、粮运将尽、江油降、绵竹战败诸葛瞻及刘禅请降。

年代交叉依据：[《三国志》卷三十三·后主传](https://zh.wikisource.org/wiki/三國志/卷33)：景耀六年即263年，记载魏军数道来攻、改元炎兴、冬季绵竹之败与请降。已在线核对这一连续段落，不把未逐段校读的其他传文作为额外叙事依据。

五段依次为：剑阁正面防守 → 阴平绕行制造两难 → 地形和补给代价 → 江油与绵竹打开腹地 → 蜀亡而魏、吴仍在。主问题是“守住了剑阁，为什么仍没守住成都？”主肖像为邓艾。

邓艾绕行的双向两难出自其计划，不能夸张成毫无风险的必胜策略。山谷、补给与行动选择一起解释结果。七百余里不能直接换算成现代道路长度。古江油城、古绵竹需与现代同名城区区分；场景镜头只表示观察范围，任何复用路线均标为示意。不把263年的魏灭蜀画成晋灭蜀，不提前讲成三国已经统一。

## 前端与素材验收要求

1. 首屏先呈现关键问题、主人物与场景；每次步进只出现一段正文和一个观察重点。
2. 年份只在用户步进时切换；九品后期明确显示西晋背景，不能沿用220年的标题遮住时代改变。
3. 资料出处和边界应可打开查阅；有关定位、路线与肖像的简短说明应在相应视图可见。
4. 肖像不放入引文气泡、不配伪造第一人称对白；艺术设计可有气质差异，不把小说脸谱当史实。
5. 三场景需要分别检查桌面与手机换步、地图镜头、文字长度和返回探索；本文件记录内容依据，不宣称前端交互已经验收。
