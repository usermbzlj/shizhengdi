## 构建与素材

最终 `npm run build` 退出码0，TypeScript与Vite构建完成。产物主JS约2,311kB / gzip675kB，CSS194.71kB / gzip33.55kB，MapLibre worker509.70kB。Vite的大包提示仍存在，未据此宣称真实设备性能达标。

`npm run lint` 退出码0，16条警告，包含hooks依赖、effect同步状态、ref及purity提示。新SceneStudio、两个研究台和旁白组件没有在最终输出中产生警告；未为消除数值而关闭lint规则。日志保存在[lint.log](lint.log)。

`data/.venv/Scripts/python.exe prototype/scripts/tts.py --scenes` 输出 `0 clips to generate`，15段音频已按当前正文生成；生成失败会退出非0，避免漏片时伪报成功。

`python docs/scene-upgrade/verify-assets.py` 通过：15个音频文件非空，文本哈希匹配，3张无损肖像逐像素相同；将三条旧事件放回再应用修订后，108条输出与当前数据一致，其他105条不变；未知事件ID报错；生成修订调用位于旧审查之后、写出之前。详见[结果JSON](asset-checks.json)。没有执行全量疆域与地形再生成。

对生产预览逐一请求15个音频和3个肖像的HEAD，均返回200，Content-Length与dist文件相同；每个场景抽取一个音频请求前1024字节，均返回206及正确的Content-Range。见[HTTP素材检查](http-asset-checks.json)。这验证实际可访问及音频分段读取，没有代替人工试听。

## 未验证

- 没有向真实DeepSeek对话服务发请求，未验收真实人物对话、模型回答和服务延迟。
- 浏览器确认音频播放与生命周期，未人工逐段试听全部15个文件，因此不能声称没有错读或语气问题。
- 这些是浏览器视口检查，未测试真实低端手机CPU、慢网首屏、长时间内存和全部网络失败路径。
- 旧疆域仍是近似地理表达；本轮核对三场景涉及的关键地点与史料层次，没有重建整个时代的历史GIS。
- 这次交付范围为三个场景与共用交互修复，不代表108条事件、48个人物和所有城市内容都已完成同等深度的重写。
