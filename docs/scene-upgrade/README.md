# 三个场景的体验重构 · 2026-09-30

赤壁之战、九品中正、阴平灭蜀已经接入原型。每场5幕，共15幕；入口现在是全页叙事舞台，配合独立的互动研究台与地图手札。可以独立打开、自由翻幕、查阅人物与史料、继续上次阅读。旁白不会替用户自动翻页。

根据用户鼓励大胆创新的方向，场景呈现已经从地图加侧栏升级为三种互补的形式。舞台用大幅肖像、宋体标题与轻描的江流、文书、山形建立叙事；研究台让观察和选择直接改变画面与解释；地图手札把关系放回空间。原有自由探索、48段导览、城市和反向穿越入口仍可使用。

## 三个场景

| 场景 | 阅读中的关键问题 | 前端呈现 |
| --- | --- | --- |
| 赤壁之战 | 为什么占住北方，仍跨不过长江？ | 周瑜叙事舞台；江面、对阵、火攻3个视角；联盟、水战适应、军队状态、火攻条件；4个地点可定位 |
| 九品中正 | 分为九等，就能让选官更公平吗？ | 陈群叙事舞台；评价依据、观察文书、评价权关系3列研究台；初建与后期切换；人才、地方、家世与异议的不同解释 |
| 阴平灭蜀 | 守住剑阁，为何仍没守住成都？ | 邓艾叙事舞台；正面与绕行路线对照；4个观察阶段与5个地点；补给代价、古江油与古绵竹辨认 |

赤壁使用208年冬的叙述，不将风向的不同史料层次混成一句。九品前3段属于220年创制，后2段明确显示西晋背景。阴平结局属于魏灭蜀，吴仍在江南；路线和锚点标注教学示意。

## 视觉与使用细节

- 以纸色、墨色和地形底图形成连续画面。赤壁用赭红，九品用灰蓝，阴平用松绿；深色主题另设可辨认的浅色强调色。
- 新增周瑜、陈群、邓艾3张一致风格的肖像。肖像用于故事封面与人物阅读；已有周瑜、邓艾身份也复用到原人物详情、地图头像和对话头像。陈群是本场景人物，不虚构其已接入旧AI人物库。
- 「故事现场」提供简短正文、观察重点、大幅肖像和五幕导航。手机肖像移至正文上方，正文在自己的区域滚动，上一幕、下一幕持续可达。
- 「拆开看看」使用宽幅纸墨地理展台和九品文书台。选项有明确的选中态，图示、观察文书与解释实际响应点击；不把史料猜测变成胜率、成绩或人物排名。
- 「地图手札」保留可拖动、缩放的地形地图，侧边或底部放当前观察说明。研究台的地点能进入地图；返回研究台后保留观察选择，刷新后也保留研究地点的来源。
- 三种视图共用阅读幕次和一份旁白，研究组件切视图时不卸载。幕次保存在本地；视图、研究地点和研究选项只存当前会话，不收集学习成绩。
- 换幕后聚焦新标题；形式页签支持方向键、Home、End。人物与史料在单独查阅框打开；背景不可操作，Escape关闭后恢复打开按钮。故事集同样保持焦点范围。
- 15段本地MP3支持暂停、继续、重听和失败重试，延续原应用静音偏好。打开查阅或故事集时暂停；已经播完的旁白关闭查阅后保持结束，重听由用户主动触发。
- 在320px手机、390px手机、820px平板、740×420短横屏与1440px桌面检查布局。长研究内容滚动阅读；短横屏使用一行顶栏，避免与正文重叠。

## 连续操作与共用框架修复

导览时打开详情会暂停，关闭后从原进度继续；静音、倍速、暂停不会重新开始该段。密集时间轴改为可点开的事件簇，窄屏仍能逐条选择。地图跨缩放档时重新更新人物显隐。

最终浏览器检查还复现了相机被布局更新打断的问题：MapLibre的 `setPadding` 内部调用 `jumpTo`，会停止正在进行的飞行。面板的尺寸观察器现在等移动结束再校正留白；故事飞行本身直接带入当前布局留白，避免停在中途的地球视角。已用重新加载、从故事集进入、换段和窗口尺寸变化重新验证。

新场景镜头增加可取消的请求所有权。快速离开地图会取消本场镜头，旧回调不会停止接续的新镜头。相机在注册自身结束事件前先停止旧运动，避免MapLibre同步发出的旧moveend提前结束新请求。[独立竞争检查](camera-race-checks.json)10项通过，可用[脚本](camera-race-checks.mjs)重跑。

## 素材、史料与生成保护

- [内容研究与核对](content-research.md)：原典链接、叙事边界、古地名位置，以及三条旧事件同步修订。
- [肖像生成模式与完整提示词](portrait-prompts.md)：内置image_gen生成，当代人物意象，不声称真实相貌复原。PNG原图在 `source-portraits/`，前端无损WebP在 `prototype/public/images/portraits/`。
- [三条旧事件备份](original-events.json)：修订前记录。其他105条没有随本轮重新编写。
- `research/scene_event_overrides.json`：已核对字段的生成修订映射，在 `build_map.py` 的旧审查建议之后应用。重新生成事件不会把赤壁空月份、风向说明或古绵竹定位改回旧值。
- `prototype/scripts/tts.py --scenes`：只生成三场景旁白，按文本哈希增量检查。音频已经随生产构建复制到 `dist/audio/`。
