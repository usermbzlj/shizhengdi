## 实际观察

### V01：同年事件按钮重叠

390×844 自由探索界面含 39 个主要事件、17 个世界事件。

- 189 年董卓进京：x=63.625，宽=17，高=17。
- 189 年董卓废立：x=63.796875，宽=17，高=17。
- 两者中心间距 0.171875 像素，几乎完全重叠。
- 208 年赤壁按钮：x=103.2578125，宽=17。
- 211 年潼关按钮：x=108.8984375，宽=17。
- 在该手机布局中，定位到“208年 赤壁之战”的按钮并点击，实际打开“潼关之战”。随后从搜索中的“赤壁之战 208 年 · 赤壁”进入，正确打开赤壁卡。

这说明按钮存在，但点击命中区域不能可靠区分目标。不是“没有事件数据”，也不能靠扩大同排按钮单独解决。

原始测量：[mobile-timeline-metrics.json](mobile-timeline-metrics.json)。误打开的现场截图：[05-mobile-misdirected-event.jpg](screenshots/05-mobile-misdirected-event.jpg)，记录从赤壁按钮点选却打开潼关的结果。准确搜索进入后的截图：[09-mobile-chibi-search.jpg](screenshots/09-mobile-chibi-search.jpg)。

### V02：静音讲述中途切速度，进度回退

桌面开启讲述，默认静音，未暂停的第 2 段仍在播放时读取进度，再点击 1× 切到 1.25×：

```json
{
  "before": { "step": "184 年 · 2 / 48", "progress": 0.742806 },
  "after": { "step": "184 年 · 2 / 48", "progress": 0.000826487 }
}
```

段落没有改变，进度从约 74.3% 回到接近 0%。与 GuidePlayer 的局部 elapsed / timer.elapsed 不同步相符。截图 07 是随后暂停的讲述画面，已进入第 3 段，不能单独作为上述瞬间数值的证据。

复现：静音讲述开始阅读 → 不暂停 → 读到一段中途 → 点击速度按钮 → 观察段号与进度。暂停后再改速属于不同路径，不能据它正常否定此问题。

### V03：打开事件详情自动推动年份

桌面点赤壁事件后，打开 208 年详情并自动重播，时间轴读数随后到达 210 年。静态代码说明任何事件卡挂载都会重播，年份推进包含前导和收尾的示意窗口。

是否应该自动播放是产品选择；当前页面没有清晰解释“历史日期”和“演示时间窗口”的区别。代码同时确认收起卡片只清延迟定时器，没有主动取消已开始的年份动画。关闭后动画是否继续的各竞争路径未逐一运行。

### V04：手机事件面板挤压地图

390×844、通过搜索准确进入赤壁后：

- 顶栏高度 86.5 像素。
- 事件面板高度 388.234375 像素。
- 底部时间轴高度 176 像素。
- 面板+时间轴合计约占屏幕高度 66.9%。
- 卡片滚动内容高度 1232 像素，可见滚动区 clientHeight=376。
- 滚动区 scrollWidth=366、clientWidth=362，存在轻微横向溢出。

原始测量：[mobile-panel-metrics.json](mobile-panel-metrics.json)。

手机讲述样本中，讲述卡高约 314.49，时间轴约 104；合计约占 844 像素高屏幕的 49.6%。本样本是桌面切换尺寸后的布局，地图焦点位置也受尺寸变化影响，不能用它断言手机首次进入一定偏离焦点。
