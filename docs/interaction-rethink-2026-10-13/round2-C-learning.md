# 第二轮 · C · 学习与叙事

## 反驳
- **A 的“下一拍”与 B 的“讲”**：节奏还给了孩子，思考没有。点五次“下一拍”仍是接收；B 的 [为什么] 按钮又是答案先于问题。
- **A 的“一键小检验”**测的是在哪/何时的识记，不是为什么；可作附加动作，不能当收尾。
- **A 的「一分钟看完这一百年」**可当全景，不能当第一屏主菜，否则是微型 48 段导览。
- **D 的卷轴**最接近，判据：一个单元里若没有一次“孩子先答、地图再回应”，它就是文章。

## 被说服并修改
- 押注改软：一下点击约 5 秒，“我不知道”算选项，永不挡路，不判对错，只说“你押 X，史书记 Y”。证据边界：Kornell 2009 等来自实验室配合被试，在家自选场景无证据；轻押注保留关键成分（推断）。
- 时长：最短 3 分钟，完整 7 分钟，古人另算。
- 删掉逐问定制工具与屏序。“一问”模板：问题、前后两个时刻、1–3 步“看”（数据声明镜头/高亮/≤60 字）、揭示、一位古人。作答动作每问挑 1–2 个：**点**（图上点地方）、**选**（2–3 选项）、**圈**（前后对照圈变化，每问必备）、**拨**（局部时间条找转折）。
 - 3 分钟版：问题+定格地图+可跳过押注 → 两步看 → 圈变化 → 揭示+“因为……”。
 - 7 分钟版：再加一次“拨”或对照案例（赤壁 vs 280 灭吴）。
- “拨”与 B 的“搓”不矛盾：有目标（找转折）、有回应（松手后对照停点）、窗口仅 2–3 年。漫无目的地拖不算学习，这点被 B 说服。
- 全景长条加动作：看完一问，把问题卡拖到百年长条上对应年份才点亮。

## 六点表态
- (a) 不是学习核心；是地图册里的玩具，问题里只以带目标的“拨”出现。
- (b) 不强制，每问最多一次默认出现、可跳过、不判对错的押注。
- (c) 第二入口“地图册”，从每问结尾进（“打开这一年的完整地图”），钉问题针作回钩。
- (d) 统一模板，每问一份配置；旗舰多配素材但不加新动作类型。
- (e) 每问结尾，可选，不设此时此地前提；古人第一句把这一问反过来问孩子。
- (f) 第一屏就是一问的第一步（定格地图上亮着押注选项），下面一排其他问题。反对输入框居主位：没有问题的孩子面对空框不知写什么。

## 先做
Figma 做赤壁 3 分钟版，“一键押注/无押注”两版各给 3 个初中生在家试；记录中途离开率、想不想再来、三天后能否一句话解释 280 年晋为何能过江。
