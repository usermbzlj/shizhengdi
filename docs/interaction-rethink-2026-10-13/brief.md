# 交互重想 · 共享材料（2026-10-13）

用户原话：“整个交互逻辑就设计得完全不合理！请你跳脱出整个设计框架和思维定势，从第一性原理出发，深入、仔细地想想。”

不变的东西：用户是初中生（12–15 岁，在家，电脑/平板/手机）；目标是“时空观念”和“区域认知”——在时间和空间里看懂历史为什么这样发生；内容范围是三国前后（184—280），之后要扩到全时段；气质现代、高级、克制。产品方案见 `产品方案.md`，上一轮全面审查见 `docs/first-principles-review-2026-10-11/report.md`（内容、AI、数据已审过，本轮只谈交互）。

其余一切——包括“满屏地图 + 底部时间轴”这个骨架本身——都可以质疑。

## 现在的交互是什么样（按代码，`prototype/src/`）

**七种模式**（`lib/store.ts`）：opening / explore / guide / scene / travel / chat，加一个盖在上面的故事集弹层。每种模式有自己的界面外壳。

**开场**（`Opening.tsx`）：地球 → 飞到中国 → 年份从 2026 倒数到 184（约 10 秒，可跳过）→ 一张卡片三个按钮：从一场故事开始 / 跟着历史走 / 自己探索地图。

**探索模式的屏幕**
- 顶栏：品牌、搜索框（城市/古地名/人物/事件/线）、「精选故事」、「跟着历史走」、「更多」弹层（家乡设置、6 个图层开关：势力范围/州界/全部事件/全部人物/古代水系/关隘，两条“线”的开关与“看故事”，旁白开关，深浅主题）。
- 底部时间轴约 204px 高（占小屏三分之一）：时代色带、刻度 160—300（数据只到 184—280）、“历史”一行和“世界”一行图标（只有图标，同一列多个事件合成一个带数字的按钮，点开弹出列表）、播放头上方大字年份 + 年号 + 当前事件名、右侧「今天」按钮。
- 拖动时间轴：地图跟手；松手有惯性，接近重大事件时吸附。←/→ 一年，Shift 跳事件。
- 地图默认“很安静”：只显示势力范围、河流、都城、城市；事件只在它“正在发生”的那半年左右出现（先出现一个大空心圈“聚拢”→ 图标落下 → 圈散开 → 留淡标记），停在两次事件之间时地图上几乎没有事件。人物默认不显示，放大到区域级或打开“全部人物”才出现。
- 点地图上的事件 / 城市 / 人物 / 家乡针：右侧弹出详情面板（约 390px）。**打开任何事件面板，年份都会被拉回事件开始前，自动重播 4—8 秒**，地图随之整体变化。城市面板有“三国时的它 / 这座城的一生”两个页签。人物面板：只有当此时此地他在地图上，才能“邀请他来到今天”。

**跟着历史走（guide）**（`GuidePlayer.tsx`，`data/chapters.json` 48 段）：画面下方一张讲述卡（标题、正文、上一段/暂停/下一段、进度条、倍速、配音开关、关闭）。每段：镜头飞过去、年份滑到事件“开场”、按阅读时长（或配音长度）计时、年份缓慢漂移、自动进下一段。从上次停下的段落静默续读。期间：搜索和“更多”被隐藏；时间轴变矮、刻度数字和年份读数被隐藏；拖时间轴 = 暂停（hold）并关掉面板；“展开详情”也 = 暂停。第 48 段之后才有“古人来访”。默认静音。

**一条线的故事**：在“更多”里打开或从搜索进入，复用 guide 的讲述卡播放 6 段。

**精选故事（scene）**（`SceneStudio.tsx` 等，3 个场景各 5 幕：赤壁、九品中正、阴平灭蜀）：整页覆盖地图的另一套界面——顶部三页签“故事现场 / 拆开看看 / 地图手札”，底部五幕导航，人物档案/史料弹窗，自己的旁白与主题按钮，“自由探索”退出。有 `?scene=` 直链。

**反向穿越（travel → chat）**（`Travel.tsx`）：在人物面板点“邀请” → 镜头飞到他所在地 → 4 秒“年份快进到 2026”过场 → 落到家乡 → 对话卡：只显示古人最新一句和“你已经讲过 N 句”，一问一答，3 问后告别，送回原年份。时间轴右侧「今天」按钮**并不去今天**：它打开“全部人物”图层，并提示“点一位此时此地的人，请他来到今天”。

**年份有 7 个写入方**：拖动、键盘、点事件（动画）、事件面板自动重播、导览、场景、穿越过场，互相抢。

## 主 Agent 实际操作时看到的（2026-10-12/13）
- 开场结束停在 184.0 年，正好是黄巾起义的“聚拢”阶段：屏幕中央一个大空心黑圈，没有图标（已临时修）。
- 播放头的年号说明和时代色带标签互相压字（已临时修）。
- 播放年份时，标注每 120ms 重新避让一次，大量标签显隐切换；每过一个疆域关键帧，疆域曾闪回上一时期几帧（均已临时修）。
- 208 年长坂之战和赤壁之战的图标叠在一起。
- 导览第一段显示“183 年”（地图提前出发）；导览中时间轴看不到年份。
- 精选故事和跟着历史走的入口按钮曾用同一个图标。
- 用户反馈：显示问题多（图像重叠、各种闪烁），交互逻辑整体不合理。
