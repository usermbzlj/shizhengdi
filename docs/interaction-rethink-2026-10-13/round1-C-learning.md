# 第一轮 · C · 学习与叙事设计视角

立场：现在把“解释为什么”交给旁白，孩子只负责看。要改最基本的单元：从“一段讲述”改成“一个孩子必须先押答案的问题”。地图和时间轴留下，但从“放映机”变成“仪器”。

## 1. 从不懂到能解释的步骤
| 步骤 | 谁做 | 依据 |
|---|---|---|
| ① 定锚：此时此地，和我知道的哪件事有关 | 可被动 | 推断 |
| ② 遇到矛盾：“按理说应该……为什么没有？” | 系统提出，孩子必须先押答案 | POE（课堂研究为主）；先测后学（Kornell, Hays & Bjork 2009） |
| ③ 在图上找线索：定位、看宽窄、算距离、上下游 | 孩子做 | 生成效应（Slamecka & Graf 1978，词表材料；迁移到地图为推断） |
| ④ 对照：同地换时刻，或同时刻换路线 | 孩子做 | 先对照再讲解（Schwartz & Bransford 1998） |
| ⑤ 揭示：史实与原文 | 可被动，但必须在②之后 | “讲授的时机” |
| ⑥ 讲给别人听：“条件—选择—结果”一句话 | 孩子做，口头或对话为佳 | 自我解释（Chi 等 1989）；书面解释几乎无效，互动讲解有效 |
| ⑦ 迁移：换个案例还能解释 | 孩子做 | 推断 |
Chi & Wylie 2014 ICAP：被动 < 操作 < 生成 < 互动。现产品几乎全在被动，最好处只是操作。纯发现式对新手也无效（Mayer 2004；Kirschner, Sweller, Clark 2006），所以“全程导览”与“静默探索”两极都不对。

## 2. 哪里让孩子变成旁观者
“地图在动、孩子在看”：地图状态由系统时钟决定，孩子只能喊停。“孩子在动、地图回应”：地图状态由孩子的假设和操作决定。
- 答案总在问题之前：s18“注意长江这条线：曹操的地盘停在江北，孙刘守江，靠的是战船和水军”——孩子还没形成“为什么过不去”，结论已给完。48 段基本都是“事件 + 一句地理归因”。
- 自动推进惩罚最主动的行为：拖时间轴 = 暂停并关面板；展开详情 = 暂停。Mayer & Chandler 2001：学习者控制节奏的分段材料优于连续播放。
- 打开面板就重播 = 抢走孩子的问题，他刚才正在对比的时刻也丢了。
- 聚拢/落下/散开只传达“这里发生了事”，说不出为什么在这里；Tversky, Morrison, Bétrancourt 2002 综述：信息等量时动画常不比静态图强；无关动效是诱人细节。停在两事件之间地图几乎空——地图只在机器转动时钟时才说话。
- 场景按媒体分页而不是按思考步骤；赤壁问题极好（“占住北方之后，为什么仍跨不过这段长江？”），但第一幕正文立刻说出答案；BattleLab 四张条件卡只是“点一下出文字”；五幕年份全固定在 208.8，场景里时间维度消失。
- 最有价值的“讲给别人听”在 48 段之后，孩子手里已没有具体问题。

## 3. 模型：“一问”单元
单元 = 一个“为什么”问题 + 一个地理机制 + 一对对照时刻 + 孩子的一次讲解收尾，8–12 分钟。节奏由孩子控制，无计时器，“下一步”只在孩子做完一个动作后出现；动画只在孩子触发且押注之后播放。年份只有两个写入方：孩子本人，以及单元进入某一步时设定的初始年份。

示例：曹操为什么没能过江？
- 第 0 屏 问题墙：6–8 个问题钉在地图上发生的位置。
- 第 1 屏 定锚：地图静止在 208 年七月，“北方已经是他的，兵也最多。”
- 第 2 屏 押注：“如果你是曹操，打孙权走哪条路？”三条路线（汉水→江陵顺江东下 / 合肥南下濡须 / 徐州→广陵渡江），选一条 + 从短语补“因为___”（选项用孩子常见想法如“兵多就能过”“风向”）；不选不能往下走，但可选“我不知道”。
- 第 3 屏 查证：时间轴锁在 208.5—209.0，由孩子拖；长坂、刘琮投降、接收荆州水军、赤壁依次出现；工具“量江宽”“看上下游”。地图只回答孩子用工具问的事。
- 第 4 屏 分类：BattleLab 四张条件卡拖进“地理条件 / 人的选择 / 偶然”三栏，拖到哪张地图高亮哪里。
- 第 5 屏 揭示：孩子点“看那一夜”，火攻动画播一次；2–3 句压缩讲述（s17/s18）；孩子分类与史家说法并排，标出“你分对的 / 史家会争论的”；“借东风”放“演义还是史书”小注。
- 第 6 屏 对照（为什么在这时）：“72 年后，晋军过江了。”时间轴跳到 279.8—280.3，孩子拖；王濬楼船从益州顺流而下。“这次和曹操那次最大的不同是什么？”孩子在图上点“船从哪里来”；提示 263 年蜀亡、上游易主，链接“守住剑阁为什么没守住成都”。
- 第 7 屏 讲给古人：曹操来访，知识停在 208 年，问“我输在哪里？下回该从哪里来？”孩子作答，他追问一次。
- 第 8 屏 手札卡：用孩子自己的话生成卡片；地图保留孩子选过的路线作为“我的图层”；推荐下一问。

## 4. 自由探索与事件动画
自由探索保留但改成“工作台”，不再是起点：每完成一问解锁一件工具（量江宽、比两年、看上下游、翻山运粮），路线、手札、问题针留在图上。空白的探索入口删掉。事件动画删聚拢与落下，只保留“结果的对比”（上一时期边界淡影叠在新边界下），只在孩子拖动时显示；面板一律不自动重播。

## 5. 内容重组
- 48 段拆成约 7 问，每段降为第 5 屏的揭示文本，地理归因句挪到押注之后：关中为什么四面挡得住却挡不住政变（s03/05/06/08）；曹操凭什么在中原站住（s09/12/14/15）；曹操为什么没能过江（s11/17/18/23/48+长江线）；江陵为什么让孙刘翻脸（s19/25/26/30）；北伐为什么总断粮（s24/34/36+秦岭淮河线）；守住剑阁为什么没守住成都（s43+阴平场景）；灭吴为什么要从益州出船（s46/47/48）。
- 制度段落（s04/28/35/45）与九品中正场景：单独“制度”书架。世界史段（s21/32/37/39）：对照屏里可选“同一时刻的世界”或删。108 事件：孩子拖时间轴时的底层内容。赤壁、阴平场景拆成“一问”的各屏，复用 BattleLab 条件卡与对照路线。2 条线 → 跨问题的“机制透镜”。48 人：每问配 1–2 位对话者。
- 不再需要：连续自动导览、计时器、倍速、静默续读、聚拢动画、面板自动重播、场景三页签、“48 段之后才来访”、10 秒倒数开场。

## 6. 最没把握
1. 孩子在家愿不愿先押答案而不嫌烦走掉。验证：6 个初一学生，现导览 vs“一问”纸面原型，记录跳过率、流失率，两天后迁移题（南宋守长江与元军突破）。
2. 三个预设选项会不会太好猜或被演义带偏。验证：先不给选项问 5 个孩子收集原话再改写成选项。
3. “孩子在动”需要可交互地图，还是静态图+问题就够。验证：纸质地图 + 尺子做对照；纸质差不多则价值在问题设计不在渲染。
