# 史政地

面向初中生的三国历史学习产品，地图与玩法并重。可运行的原型在 `prototype/`，运行方法见 [prototype/README.md](prototype/README.md)。

| 位置 | 内容 |
| --- | --- |
| `prototype/` | Web 原型：游戏大厅、几种玩法、地图资料馆、DeepSeek 对话代理、数据构建与推演脚本 |
| `research/` | 史料调研底稿；`fact_corrections.json`、`scene_event_overrides.json` 是构建时应用的史实修正 |
| `data/` | 原始与派生地理数据、Python 环境（都不进版本库），清单见 [data/SOURCES.md](data/SOURCES.md) |
| `docs/` | 审查、设计与验证记录，索引见 [docs/README.md](docs/README.md) |
| `tools/shot/` | 无头浏览器截图工具，场景配置在 `scenes/` |
| `产品方案.md` | 最初的产品方案 v0.2 |
| `史政地.docx` | 最初的构想文档 |
